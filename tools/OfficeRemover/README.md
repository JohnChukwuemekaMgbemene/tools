# OfficeRemover

Cleanly removes Microsoft Office installations from Windows machines.

## Download

Get the latest version from the [Releases](https://github.com/JohnChukwuemekaMgbemene/tools/releases?q=OfficeRemover) page — look for tags starting with `OfficeRemover-v`.

### Assets

| File | Description |
|------|-------------|
| `OfficeRemoval-vX.Y.Z-Setup.exe` | Installer |
| `OfficeRemoval-vX.Y.Z-Portable.exe` | Portable executable (no install needed) |
| `OfficeRemoval-vX.Y.Z-win-x64.zip` | ZIP archive |

## Usage

Run the executable and follow the on-screen prompts to detect and remove Office installations.
